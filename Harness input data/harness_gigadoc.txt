# Harness Gigadoc

LLM-ready consolidation of the uploaded Excel workbooks.

Conventions:
- Each workbook becomes one section.
- Repeated workbook metadata is listed once per workbook instead of repeated on every sheet.
- Tables are flattened into TSV blocks for compactness and easy copy/paste into LLMs.
- Entirely empty columns are removed from each table.
- Zero-row sheets are preserved in the index and omitted from detailed sections.
